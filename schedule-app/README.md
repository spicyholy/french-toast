# 온유 일정

로그인 없이 사용하는 개인 일정 관리 웹앱입니다. 월간 달력과 날짜별 일정, 일정 추가·수정·삭제, 제목·메모 검색, 분류 필터를 제공합니다. 모바일 화면과 키보드 조작을 지원합니다.

## 실행

`schedule-app` 디렉터리에서 다음 명령을 실행한 뒤 <http://localhost:4173>을 여세요.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

빌드나 패키지 설치가 필요 없습니다. `dist/index.html`을 직접 열 수도 있지만, 파일 URL의 브라우저 저장 정책은 브라우저마다 다르므로 위 서버 방식을 권장합니다.

## 사용

날짜를 선택하고 **새 일정 만들기** 또는 **이 날에 일정 추가**를 누릅니다. 제목, 날짜, 시작·종료 시간, 분류, 메모를 입력하세요. 같은 날에 끝나는 일정만 지원합니다. 오른쪽 일정 카드에서 수정하거나 삭제할 수 있습니다. 삭제에는 확인 단계가 있습니다. 검색은 제목과 메모를 함께 검사하며, 선택한 분류 조건과 동시에 적용됩니다.

일정은 현재 브라우저와 접속 주소의 `localStorage`에만 저장됩니다. 다른 기기·브라우저·접속 주소와 공유되거나 동기화되지 않습니다. 브라우저 데이터를 삭제하면 일정도 삭제됩니다. 시크릿 모드에서는 창을 닫을 때 데이터가 사라질 수 있습니다.

저장에 실패하면 화면에 안내와 **다시 시도**가 표시됩니다. 저장된 데이터를 읽지 못했거나 형식이 손상된 경우 기존 기록을 보호하기 위해 편집을 잠급니다. 이때 다시 시도는 읽기만 수행하며, **저장 데이터 초기화**를 확인해야 기존 데이터를 지우고 새로 시작합니다. 정상적으로 불러온 뒤 저장에 실패한 변경사항은 화면에 유지됩니다. 저장 성공 전에는 새로고침하지 마세요.

## 파일

- `dist/index.html`: 한국어 인터페이스
- `dist/styles.css`: 반응형 스타일
- `dist/model.js`: 날짜·검증·검색·저장 모델 (CommonJS에서도 불러오기 가능)
- `dist/app.js`: 화면과 사용자 동작
- `docs/design.md`: FT-SCHEDULE-001 설계와 검증 기준

반복 일정, 알림, 계정, 외부 캘린더 연동, 여러 탭 동시 편집은 지원 범위에 포함하지 않습니다.
