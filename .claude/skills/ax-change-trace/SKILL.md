# AX 변경 경로 추적

문서 유형 · 저장소 변경 분석 스킬\
상태 · 적용 중\
갱신일 · 2026-11-11\
관련 요구사항과 문서 · [PRD](../../../docs/prd/product.md), [구현 명세 예시](../../../docs/implementation/000_example.md), [공통 규칙](../../../.agent/standards.md)

1. 요구사항 ID별로 사용자가 하는 일과 관찰할 결과를 한 문장으로 적는다. 기존 호출자와 데이터가 지켜야 할 계약을 함께 확인한다.
2. 실제 진입점에서 입력 검사, 모듈과 저장소 경계, 출력과 실패 경로를 따라간다. 파일과 심볼을 남기고 확인한 사실과 설계 가정을 구분한다. 새 기능은 예정된 진입점과 호출자 사용 예로 계약을 구체화한다. 변경의 영향을 받는 진입점과 호출자부터 확인한다. 공통 경계나 대체 경로 때문에 다른 동작이 바뀔 수 있으면 추적 범위를 넓힌다.
3. 기존 호출자, 이전 데이터, 공개 오류와 재시도에 미칠 영향을 확인한다. 중요한 설계 결정은 대안별로 사용법, 제약, 호환성 및 검증 비용을 비교한다.
4. 검토 시 구현자의 설명과 별도로 계약을 어길 수 있는 조건을 구체화한다. 재현할 수 있으면 관찰을 남기고, 정적 근거라면 어떤 호출과 상태가 결론으로 이어지는지 설명한다.
